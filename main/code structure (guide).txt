----- 🟦 HTML (Structure of the Website) -----
<html>
- The main container of the whole webpage

<head>
- Contains settings and links (not visible on the page)

<meta>
- Sets character encoding and responsiveness (mobile-friendly)

<title>
- The name shown in the browser tab

<link rel="stylesheet">
- Connects your CSS file (hr-css.css)


----- 🟦 <body> -----
Contains everything visible on the webpage


----- 🔷 Header Section -----
<header>
- Top bar of the website

<h1>
- Displays the title: Human Resources Department Portal

<img>
- Shows the logo image


----- 🔷 Sidebar Navigation -----
<nav>
- Sidebar menu for navigation

<ul> / <li>
- Creates a list of menu items

<a>
- Clickable links (Home, Dashboard, etc.)

<div class="clock">
- Displays time and date


----- 🔷 Main Content Area -----
<main>
- Where all page content appears


----- 🔷 Hero Section (Slider) -----
<div class="hero-section">
- Big banner area at the top (yung image)

<div class="slide">
- Each slide (image + text)

<img>
- Background image of slide

<div class="hero-overlay">
- Text on top of image

<span class="dot">
Navigation dots for slides


----- 🔷 HR Resources Section -----
<section>
- A grouped section of content

<div class="resource-card">
- Small cards (Job, Forms, Internships)


----- 🔷 Placeholder & Parallax -----
<div class="image-stack">
- Sliding background images

<div class="parallax-section">
- Background moves when scrolling (parallax effect)


----- 🔷 Dashboard (Hidden by default) -----
<div id="dashboard">
- Placeholder for dashboard content


----- 🔷 Employee Management -----
<table>
- Displays employee data

<thead>
- Table header (column titles)

<tbody>
- Table content (rows)

<input>
- Search bar

<button>
- Add employee button


----- 🔷 Modals (Pop-up Windows) -----
<div class="modal">
- Hidden popup

Login Modal
- Username + password form

Employee Modal
- Form to add/edit employee


----- 🔷 Download Section -----
<div class="download-card">
- Each downloadable file

<a>
- Download button


----- 🔷 Canvas & Floating Icons -----
<canvas>
- Used for particle animation

<div class="floating-icon">
- Floating emojis





----- 🟩 CSS (Design & Styling) -----
*
- Applies to all elements (reset spacing)

body
- Sets font, background image, and overall look

.header
- Styles top bar (blur, fixed position)

.sidebar
- Left menu (fixed position, vertical layout)

.main-content
- Right side content area

.hero-section
- Styles big image slider

.slide
- Each slide is hidden by default

.slide.active
- Only active slide is visible

.hero-overlay
- Text over the image with animation

.card
- Small content boxes

.btn
- General button style

.btn-primary
- Blue button

.btn-danger
- Red button

.emp-table
- Styles employee table

.modal
- Full screen dark background for popup

.modal-content
- White box inside modal

.download-card
- Cards for downloadable forms

.parallax-section
- Background that moves while scrolling

.image-stack
- Sliding image animation

.hr-resources
- Section with resource cards





----- 🟨 JavaScript (Functionality / Logic) -----
document.addEventListener('DOMContentLoaded')
- Runs code when page fully loads

🔷 showHome()
- Shows home sections
- Hides other sections

🔷 Parallax Effect
- Moves background when scrolling

🔷 Floating Emojis
- Assigns emoji icons to floating elements

🔷 Canvas Particles
- Creates moving dots animation

🔷 Hero Slider
showSlide(index)
- Shows selected slide

setInterval(...)
- Automatically changes slide every 5 seconds

🔷 Navigation Links
Clicking sidebar links:
- Hides other sections
- Shows selected section

🔷 Download Section
- Shows download page when clicked

🔷 Image Stack Slider
- Changes background images every 4 seconds

🔷 Clock
updateClock()
- Shows Philippine time
- Updates every second

🟥 Employee Management Logic
employees
- Stores employee data
- Saved in localStorage

renderEmployees()
- Displays employees in table

showEmpModal()
- Opens form (add/edit employee)

hideEmpModal()
- Closes form

editEmployee(id)
- Loads selected employee into form

deleteEmployee(id)
- Removes employee
